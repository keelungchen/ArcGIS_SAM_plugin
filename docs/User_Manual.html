SAM3 Segmentation Toolbox for ArcGIS Pro

以 SAM / RITM 深度學習模型在 ArcGIS Pro 中進行影像分割 — 安裝、使用與更新手冊（v2.6.0，適用 ArcGIS Pro 3.x，含 3.6.1）

總覽 系統需求 安裝 工具箱使用 即時互動編輯（Add-in） 技巧與建議 疑難排解 後續更新

1. 總覽

本插件讓你直接在 ArcGIS Pro 內使用 Meta 的 Segment Anything Model 3 (SAM 3) 對影像圖層進行分割，並將結果輸出為 Polygon 圖徵類別（含信心分數欄位 Score 與提示來源欄位 Prompt）。它包含兩個部分：

元件形式用途
SAM3 工具箱Python Toolbox（SAM3_Toolbox.pyt）批次式分割：文字／點／框提示、自動全分割（工具 1–5），操作介面與內建 GP 工具相同
SAM3 Interactive Add-inC# Add-in（SAM3Interactive.esriAddinX）＋本機 Python 推論伺服器即時互動編輯（類 TagLab）：直接在地圖上點正負點，每點一下立即預覽遮罩，滿意後按空白鍵建立 polygon（見第 5 章）
架構說明：SAM 3 需要 PyTorch，只能在 Python 環境執行；而「逐次點擊、即時預覽」需要地圖滑鼠事件，只有 C# Add-in 做得到。 因此即時互動功能採用「C# Add-in（前端，抓點擊、畫預覽、寫入圖徵）＋ 常駐 Python 伺服器（後端，在 sam3_env 內跑 SAM 3，僅限本機 127.0.0.1）」的組合， 互動邏輯（工作區凍結、embedding 快取、每點即時推論）比照 TagLab 的 Positive/Negative Clicks 工具實作。

提供的五個工具

工具提示方式用途
1 - Segment With Text Prompt文字（英文名詞短語）在指定範圍內找出並分割「所有」符合描述的物件，例如 building、red car、fish pond
2 - Segment With Point PromptsPoint 圖徵（提示點）用點擊位置指定要分割的物件；可用欄位標記前景(1)/背景(0)點
3 - Segment With Box PromptsPolygon 圖徵（提示框）每個多邊形的外接矩形（envelope）作為一個框提示，各分割出一個物件
4 - Segment Everything自動（規則網格點）在指定範圍內自動分割所有可辨識的物件
5 - Interactive Edit (Positive/Negative Clicks)直接在地圖上點擊正點（物件內）/ 負點（物件外）類 TagLab 的互動式編輯：少量點擊即自動推測物件邊界，結果直接累加到指定的 Polygon 圖層。只分析目前地圖視窗範圍，適合超大影像

2. 系統需求

項目需求
ArcGIS Pro3.x（本手冊以 3.6.1 為準），Standard 或以上授權皆可（僅用到基本 GP 工具）
作業系統Windows 10 / 11（64 位元）
GPU（強烈建議）NVIDIA GPU、VRAM ≥ 8 GB、驅動程式為近期版本。無 GPU 也可用 CPU 執行，但單次推論可能需要數十秒至數分鐘
硬碟空間約 15 GB（複製 conda 環境 ~7 GB + PyTorch ~3 GB + SAM 3 模型權重 ~3.5 GB）
網路安裝套件與首次下載模型時需要連線；之後可離線使用
Hugging Face 帳號免費註冊即可。SAM 3 模型（facebook/sam3）為「gated model」，需先在網頁上同意授權條款

3. 安裝步驟

最快的方式——一鍵安裝包： 如果你拿到的是 ArcGIS_SAM_plugin_Setup.zip（在開發機用 scripts\make_package.ps1 產生），只要：
  1. 解壓縮到任意資料夾（例如桌面）。
  2. 關閉 ArcGIS Pro，雙擊 INSTALL.bat。
安裝程式會自動完成本章＋第 5 章的全部步驟：檢查 ArcGIS Pro 版本與磁碟空間 → 建立 sam3_env 環境 → 自動偵測 NVIDIA GPU 並安裝對應的 PyTorch → 安裝其餘套件（含 RITM 相依） → 把執行檔複製到 %LOCALAPPDATA%\SAM3Interactive\app（解壓的資料夾之後可刪）→ 寫入設定檔（8765 埠被占用時自動改用其他埠）→ 安裝 Add-in → 最終驗證。 每一步失敗都會以 PROBLEM／FIX 兩行說明「哪裡出問題、怎麼解決」， 完整記錄在 install.log；修正後再雙擊一次即可（已完成的步驟會自動跳過）。 進階選項：INSTALL.bat -Recreate（重建環境）、INSTALL.bat -CpuOnly（強制 CPU 版 PyTorch）。 安裝包內含 RITM 珊瑚模型權重，目標電腦不需要另外下載。
純 RITM 版：只用 Click Segment ＋ RITM 的話，改雙擊 INSTALL_RITM_ONLY.bat（或使用 ArcGIS_SAM_plugin_RITM_Setup.zip，以 scripts\make_package.ps1 -RitmOnly 產生）。它會略過 transformers／accelerate／huggingface_hub 與 SAM 地理處理工具箱，功能區下拉選單也只會列出 RITM。 步驟數一樣、最花時間的兩步（複製 conda 環境、安裝 PyTorch）也不變，省下的是幾百 MB 下載量、Hugging Face 帳號，以及 transformers 版本衝突這類安裝失敗。
以下各節是手動安裝的等效步驟，一鍵安裝成功的話可以直接跳到第 5.3 節。

步驟 1：建立 Python 環境（一鍵腳本）

  1. 先關閉 ArcGIS Pro（環境複製時 Pro 不可開啟）。
  2. 雙擊執行 scripts\setup_env.bat。腳本會依序：
    • 用 ArcGIS Pro 內建 conda 複製 arcgispro-py3 為新環境 sam3_env
    • 詢問安裝 GPU（CUDA）或 CPU 版 PyTorch — 有 NVIDIA 顯卡請選 G
    • 安裝 transformers（含 SAM 3 支援）、accelerate、huggingface_hub、pillow
    • 執行 proswap 將 ArcGIS Pro 的作用中環境切換為 sam3_env
注意：若 ArcGIS Pro 安裝在非預設路徑（不在 C:\Program Files\ArcGIS\Pro）， 請先用記事本編輯 setup_env.bat 開頭的 PRO_PY_ROOT 變數。

不想用腳本的話，也可以在 ArcGIS Pro 的 Package Manager（設定 → Package Manager）手動複製環境並切換， 再開啟 Python Command Prompt（開始選單 → ArcGIS 資料夾）執行：

activate sam3_env
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu126
pip install --upgrade "transformers>=4.57" accelerate huggingface_hub pillow

（無 GPU 時第一行 pip 改為 pip install torch torchvision。）

步驟 2：取得 SAM 3 模型下載權限

  1. 用瀏覽器開啟 https://huggingface.co/facebook/sam3，登入 Hugging Face 帳號並點選同意授權（Request access / Agree）。
  2. 到 Settings → Access Tokens 建立一個 Read 權限的 token。
  3. 開啟「Python Command Prompt」，執行： 
    activate sam3_env
hf auth login
    貼上 token 完成登入。（舊版指令為 huggingface-cli login，二者皆可。）

步驟 3：驗證安裝

activate sam3_env
python "此專案路徑\scripts\check_install.py"

全部顯示 [ OK ] 即成功。加上 --download 參數可順便預先下載模型權重（約 3.5 GB，只需一次，之後快取於 %USERPROFILE%\.cache\huggingface）：

python "此專案路徑\scripts\check_install.py" --download

步驟 4：在 ArcGIS Pro 加入工具箱

  1. 啟動 ArcGIS Pro，開啟你的專案。
  2. 先確認環境已切換：Project → Package Manager，Active Environment 應顯示 sam3_env。若不是，點選切換後重啟 Pro。
  3. 在 Catalog 窗格 → Toolboxes 上按右鍵 → Add Toolbox → 選擇 SAM3_Toolbox.pyt。
  4. 展開後即可看到五個工具。建議在 Catalog 對專案按右鍵將工具箱設為預設或加入 Favorites 方便日後使用。
提示：首次執行任一工具時會載入（或下載）模型，需等待較久；同一個 ArcGIS Pro 工作階段內再次執行會重用已載入的模型，速度快很多。

4. 工具箱使用方式

通用觀念

  • 處理範圍（Processing Extent）優先順序：Area of Interest 多邊形圖層 → 提示圖徵範圍（自動外擴 25%）→ 目前地圖視窗範圍 → 整張影像。SAM 是逐影像處理的模型，請盡量縮小範圍（縮放地圖到目標區，或畫一個 AOI 多邊形），結果更準、速度更快。
  • Max Image Size：送入模型的影像長邊上限（預設 2048 px）。範圍太大會自動重採樣降低解析度 — 若覺得邊界太粗糙，請縮小範圍而不是調大此值。
  • 輸出皆為 Polygon 圖徵類別，欄位：gridcode（物件編號）、Score（信心/品質分數）、Prompt（提示來源）。
  • 輸入影像可為任何 arcpy 支援的柵格（GeoTIFF、影像服務、鑲嵌資料集…）；多波段取前三波段當 RGB，非 8-bit 影像自動做 2–98 百分位拉伸。

工具 1：Segment With Text Prompt（文字提示）

  1. 將地圖縮放到目標區域（或準備一個 AOI 多邊形圖層）。
  2. 開啟工具，設定：
    • Input Raster：影像圖層
    • Text Prompt：簡短英文名詞短語，如 building、solar panel、boat、tree canopy
    • Confidence Threshold：預設 0.5；漏抓調低、誤抓調高
    • Output Polygon Feature Class：輸出位置
  3. 執行。模型會找出範圍內「所有」符合描述的物件實例。
SAM 3 的文字提示適合「簡短名詞短語」（可含屬性，如 red roof building），不是長句子。請使用英文。

工具 2：Segment With Point Prompts（提示點）

  1. 建立一個 Point 圖徵類別，在想分割的物件上各點一點（用編輯工具數位化）。
  2. （選用）新增短整數欄位如 label：1=前景（要的物件）、0=背景（要排除的區域）。不設定欄位時全部視為前景。
  3. 開啟工具：
    • Prompt Points：剛才的點圖層
    • Label Field：（選用）前景/背景欄位
    • All points describe ONE object： 勾選 = 所有點合起來描述「同一個」物件（例如一個大操場點 3 點）； 不勾（預設）= 每個前景點各自分割出一個物件，背景點套用到所有物件
  4. 執行。未指定 AOI 時，處理範圍自動取「點的外框外擴 25%」。

工具 3：Segment With Box Prompts（提示框 / Polygon）

  1. 建立一個 Polygon 圖徵類別，在每個目標物件外圍畫一個大致框住它的多邊形（矩形最直覺；非矩形也可，會取其外接矩形當框）。
  2. 開啟工具，指定 Prompt Polygons 與輸出位置，執行。
  3. 每個輸入多邊形會得到一個精確貼合物件邊界的輸出多邊形。
框提示通常是「指定單一物件」最穩定的方式，比單點提示更不容易分割出錯誤的部位。

工具 4：Segment Everything（自動全分割）

  1. 務必先縮小範圍（縮放地圖或給 AOI），否則耗時極長。
  2. 參數：
    • Grid Points Per Side：取樣網格密度（預設 32 → 1024 個提示點）。物件小而多時調高（如 48–64），大物件為主時可降低
    • Min Mask Quality Score：品質門檻（預設 0.7），雜訊多時調高
  3. 執行。重疊的候選遮罩會依 IoU 自動去重。

工具 5：Interactive Edit（正負點互動編輯，類 TagLab）

這是模仿 TagLab「Positive/Negative Clicks Segmentation」的編輯流程： 直接在地圖上點幾個正點（物件內部）、必要時加幾個負點（物件外部、要排除的區域）， 模型自動推測物件邊界並把多邊形加入（Append）你指定的目標圖層。一次分割一個物件，反覆執行即可逐一數化。

重要：此工具只分析「目前地圖視窗範圍」內的影像。 這是為了讓超大影像（大型正射鑲嵌、無人機拼圖等）也能秒級回應 — 請先把地圖縮放到目標物件， 讓物件在畫面中佔明顯比例（建議佔畫面 1/10 以上），再執行工具。落在視窗外的點擊會被略過。

一次性準備：建立目標圖層

  1. 在 Catalog 對你的地理資料庫（.gdb）按右鍵 → New → Feature Class，類型選 Polygon（例如命名 seg_results），完成後加入地圖。
  2. 之後所有分割結果都會累加到這個圖層（工具會自動補上 Score 與 Prompt 欄位）。

操作步驟

  1. 把地圖縮放到目標物件。
  2. 開啟工具 5 - Interactive Edit (Positive/Negative Clicks)，設定：
    • Input Raster：影像圖層
    • Positive Clicks：點選參數旁的鉛筆（編輯）圖示後，直接在地圖上點擊物件「內部」1–5 個點。單一明確的物件通常 1–2 點就夠；形狀複雜或細長的物件多點幾個分散的點
    • Negative Clicks（選用）：在物件「外部」但容易被誤含進來的區域點擊（例如緊鄰的相似物件、陰影、背景）
    • Target Polygon Layer：剛才建立的結果圖層
    • Smooth polygon boundary：預設勾選，輸出平滑邊界；需要逐像素精確邊界時取消勾選
  3. 執行（Run）。幾秒內（GPU）結果多邊形就會出現在目標圖層中。
  4. 結果不理想時：不必重畫 — 在圖層中刪除剛產生的多邊形，於工具中增／刪幾個點（多加正點涵蓋漏掉的部分、多加負點排除誤含的部分），再按 Run。
  5. 換下一個物件：平移／縮放地圖到新目標，用參數旁的清除（×）或編輯功能移除上一輪的點，重新點擊並執行。
使用技巧：
  • 第一個正點盡量點在物件「中心」；負點點在模型容易誤判的邊界外側最有效。
  • 邊界精度由畫面解析度決定：放大 = 邊界更準。若訊息顯示影像被重採樣（resampling），代表視窗範圍相對太大，再放大一點。
  • Geoprocessing 窗格可保持開啟，配合地圖平移縮放連續作業，工作流程與 TagLab 相當接近。
  • 模型只在第一次執行時載入，同一個 Pro 工作階段內後續每次點擊分割都很快。

5. 即時互動編輯（C# Add-in，類 TagLab）

這是本插件的核心編輯功能，完整重現 TagLab「Positive/Negative Clicks Segmentation」的即時體驗—— 直接在 ArcGIS Pro 地圖上左鍵點正點、右鍵點負點，每點一下遮罩預覽立即更新（半透明青色覆蓋層）， 滿意後按空白鍵才把 polygon 寫入目標圖層。

5.1 運作原理與大影像處理

  • 工作區（Work Area）：啟用工具後第一次點擊時，會把「目前地圖視窗範圍」凍結為工作區（地圖上顯示白色虛線框），只把這塊影像送進模型——超大影像（大型正射鑲嵌）也能即時反應。放大越多、邊界越準。
  • 可切換的後端引擎（見 5.5）：
    • RITM（預設，ritm_corals.pth，~130MB）：與 TagLab 正負點工具完全相同的網路與珊瑚微調權重，每次點擊跑一次小網路（含上一次遮罩的迭代修正），CPU 也順，幾乎不佔 VRAM，而且不需要 embedding 階段，所以工作區幾乎馬上就緒。
    • SAM（facebook/sam2.1-hiera-tiny，~155MB、免申請授權、載入數秒）：工作區建立時計算一次影像 embedding，之後每次點擊只跑輕量解碼器，毫秒級回饋。SAM 權重只有在你於 Model 下拉選單真的選了 SAM 才會載入。
  • Esc 只會清除目前的正負點，工作區（與已算好的影像 embedding）會保留，可立即重新點擊。要換到新的視窗範圍，請按功能區的 New Work Area（以目前視窗重建工作區）或 Cancel Work Area（純粹取消）。
  • 點到工作區（白色虛線框）外面時，該點會被忽略並跳出提醒，不會重建工作區——不用擔心誤點浪費時間。
  • 「Preparing work area」可以中途取消：準備過程不再跳出擋住畫面的進度視窗，按 Esc、功能區 Cancel Work Area 或面板的 ✖／↺ 按鈕即可立即中止。另外，視窗範圍在原始解析度下超過約 5 億像素時，伺服器會直接回報錯誤請你先放大，不會悶著跑好幾分鐘看起來像當掉。
  • 切換到其他編輯工具（選取、分割、屬性窗格…）不會失去工作區——正負點、預覽與工作區都會保留，切回 Click Segment（或用功能區按鈕）即可繼續。功能區的 Undo Point／Clear Points／Cancel Work Area 在其他工具作用中也能使用。
  • 每次按空白鍵儲存後，新 polygon 會自動被選取，可直接開「屬性（Attributes）」窗格填屬性、或用分割等選取型編輯工具處理。
  • 沒有在「Target」選圖層、地圖上也沒有可編輯的 polygon 圖層時，第一次儲存會自動在專案預設地理資料庫建立 SAM_Segments 圖層（含 Score／Prompt 欄位）並加入地圖。
  • 後端是一個只綁定 127.0.0.1 的本機 Python 伺服器（python_server\sam_server.py，在 sam3_env 內執行），由 Add-in 自動啟動，不對外開放；就算後端異常結束也不影響 ArcGIS Pro，按 Start SAM Server 重啟即可。

5.2 安裝（一次性）

  1. 先完成第 3 章的 Python 環境安裝（sam3_env）。
    既有環境補裝一個套件即可：activate sam3_env 後 pip install scikit-image（新版 setup_env.bat 已包含）。
    注意：Add-in 預設引擎 RITM 與備援的 facebook/sam2.1-hiera-tiny 都 不需要 Hugging Face 授權申請；第 3 章的授權步驟只有「工具箱的 SAM3 工具」與改用 SAM3 當互動後端時才需要。
  2. 雙擊 csharp_addin\dist\SAM3Interactive.esriAddinX → 按「Install Add-In」。
  3. 雙擊執行 scripts\install_addin_config.bat，寫入設定檔（Python 路徑、伺服器腳本位置、埠號）。設定檔位於 %LOCALAPPDATA%\SAM3Interactive\config.json，之後可從功能區的 Server Settings 按鈕開啟修改。
  4. 啟動 ArcGIS Pro，功能區應出現 SAM Segmentation 頁籤。
注意：影像必須是本機檔案型柵格（GeoTIFF、檔案地理資料庫柵格、鑲嵌資料集等）； 網路影像服務（WMS/影像服務圖層）不支援——後端需要直接讀取影像來源。

5.3 操作流程

  1. 準備一個 Polygon 目標圖層加入地圖（建議欄位：Score（Double）、Prompt（Text, 255），有的話會自動填值；沒有也能用）。
  2. 在 SAM Segmentation 頁籤：
    • 通常什麼都不用做：ArcGIS Pro 啟動約 10 秒後，推論伺服器會自己在背景啟動並暖機（含 arcpy 載入與模型，約 20–60 秒，一次性），所以你切到 Click Segment 時不必等待。要手動觸發可按 Start Server；要完全關掉自動啟動，在 config.json 設 "auto_start_server": false。
    • Imagery：選要分割的影像圖層；Target：選結果要寫入的 Polygon 圖層（不選則自動取地圖中第一個符合的圖層）。
    • Model：直接下拉切換 RITM（預設）／SAM2.1 Tiny／SAM2.1 Small／SAM3，選擇會自動記住，不需改任何設定檔；選了之後新模型會立刻在背景開始載入，並從下一個工作區開始生效。
  3. 把地圖縮放到目標物件，點 Click Segment 啟用工具（或直接按 New Work Area，會自動啟用工具並以目前視窗建立工作區）。此時地圖左上角會出現操作面板：即時顯示目前模型、正負點數量與分數、下一步提示，並有四個按鈕——✔ Save（同空白鍵）、↶ Undo（同 Ctrl+Z，退回上一點）、✖ Clear（同 Esc，清掉全部點、保留工作區）、↺ New Area（以目前視窗重建工作區）。
  4. 開始點擊：
    操作功能
    左鍵正點（物件內部，綠色圓點）→ 立即顯示遮罩預覽
    右鍵負點（要排除的區域，紅色叉叉）→ 預覽立即修正
    空白鍵 或面板「✔ Save」確認：把預覽 polygon 寫入目標圖層（含 Score），點擊清空，可直接圈下一個物件
    Ctrl+Z、面板「↶ Undo」或功能區 Undo Point撤銷上一個點（預覽同步回退）
    Esc、面板「✖ Clear」或功能區 Clear Points清除目前全部正負點與預覽（保留工作區，立即重新點擊）
    功能區 New Work Area 或面板「↺ New Area」以目前地圖視窗重建工作區（平移／縮放到新區域後使用）
    功能區 Cancel Work Area取消工作區與所有點（不建立新的）
    點到工作區外該點被忽略並跳出提醒（不會重建工作區）
  5. 全部完成後：Edit → Save 儲存編輯（Add-in 走標準編輯流程，結果先進入編輯暫存）。不用時可按 Stop SAM Server 釋放 GPU 記憶體。
點擊技巧（與 TagLab 相同）：第一個正點點物件中心；模型誤含隔壁物件時在該處補一個負點； 細長／複雜形狀多放幾個分散的正點；通常 1–4 個點就能得到理想邊界。訊息提示「resampling」表示視窗範圍太大被降採樣，請再放大。

5.4 後端引擎切換（SAM ⇄ RITM）

直接用功能區的「Model」下拉選單切換即可——選擇會自動寫入設定檔並記住，從下一個工作區（按 New Work Area、或存檔後的下一次點擊）開始生效，不需重啟伺服器或手動改檔。 下表是各選項的特性（進階使用者仍可從「進階設定」直接編輯 %LOCALAPPDATA%\SAM3Interactive\config.json）：

設定模型特性適用
"engine": "ritm"（預設）ritm_checkpoint 指定，預設 models\ritm_corals.pth（TagLab 珊瑚微調權重）與 TagLab 正負點工具完全相同；載入 1–3 秒、CPU 可用、幾乎不會 CUDA OOM、不需 embedding 階段珊瑚礁／底棲正射影像，或無 GPU 的機器
"engine": "sam"model_id 指定，預設 facebook/sam2.1-hiera-tiny；也可填 facebook/sam2.1-hiera-small 或 facebook/sam3載入數秒、每點毫秒級（embedding 快取）、免申請授權（SAM3 除外）一般地物（建物、船、農塘、樹冠…）

預設是 RITM：伺服器啟動時只會預先載入 RITM 這個小網路，不會去載入或下載 SAM 權重； 只有當你在 Model 下拉選單選了任一個 SAM 模型時，才會（在背景）載入該模型。若 models\ritm_corals.pth 不存在，則自動退回 facebook/sam2.1-hiera-tiny。

啟用 RITM（一次性）：雙擊執行 scripts\get_ritm.bat——會自動下載官方 RITM 原始碼（isegm）、TagLab 的 ritm_corals.pth 權重、 安裝 opencv-python／easydict，並把設定檔切到 engine = "ritm"。安裝包已內含這份權重，通常不需要另外執行。

改了 C# 程式碼、或 ArcGIS Pro 大版本升級後，需重建 .esriAddinX：

powershell -ExecutionPolicy Bypass -File scripts\build_addin.ps1
:: 或建置後直接註冊到 Pro：

  • Pro 升級到 3.7/4.0 時：把 csharp_addin\SAM3Interactive\SAM3Interactive.csproj 中的 Esri.ArcGISPro.Extensions30 版本與 Config.daml 的 desktopVersion 改成對應版本後重建。

6. 技巧與建議

  • 邊界精度取決於送入模型的像素解析度：範圍越小、解析度越高、邊界越準。同一批物件可先用文字/自動工具粗抓，再用框提示逐一精修。
  • 輸出想要平滑邊界，可後處理：Pairwise Buffer（0 距離修復）、Simplify Polygon 或 Smooth Polygon。
  • GPU VRAM 不足（CUDA out of memory）時：調低 Max Image Size（如 1024）、縮小範圍、或關閉其他佔用 GPU 的程式。
  • NDVI、DEM 等單波段資料也能用（自動轉灰階 RGB），但 SAM 3 是以自然影像訓練的，衛星/航照 RGB 效果最好。
  • 常用參數組合可存成 Geoprocessing History → Save As Tool 或建立 ModelBuilder 模型批次化。

8. 後續更新如何處理

8.1 更新插件程式碼

  1. 備份整個 ArcGIS_SAM_plugin 資料夾（直接複製一份即可）。
  2. 用新版檔案覆蓋 SAM3_Toolbox.pyt 與 sam3_tools\ 資料夾。路徑不要改變，已加入專案的工具箱參照的是檔案路徑，路徑不變就不需重新加入。
  3. 在 ArcGIS Pro 的 Catalog 對工具箱按右鍵 → Refresh（或重啟 Pro）。
  4. Add-in 部分：若 csharp_addin\ 或 python_server\ 有更新——
    • 只有 python_server\ / sam3_tools\ 變動：覆蓋檔案後按功能區 Stop SAM Server 再 Start SAM Server 即生效，Add-in 不用重裝。
    • csharp_addin\（C#）變動：取得新的 SAM3Interactive.esriAddinX 雙擊重新安裝（或依 5.5 節自行重建），並重啟 Pro。
建議把此資料夾納入 git 版本控制（git init），每次更新前先 commit，出問題可隨時 git checkout 回上一版。

8.2 更新 Python 套件（transformers / PyTorch）

activate sam3_env
pip install --upgrade transformers accelerate huggingface_hub
python "專案路徑\scripts\check_install.py"
注意：更新前先確認目前可用（跑一次工具）。若更新後出錯，可鎖回舊版，例如： pip install "transformers==4.57.*"。PyTorch 一般不需要頻繁更新，除非新版 transformers 要求。

8.3 更新 / 更換 SAM 模型

  • Meta 若釋出新版權重（例如 facebook/sam3.1 之類的新 repo），不需改程式：每個工具的 Advanced → Model ID 參數填入新的 Hugging Face repo id 即可（首次會自動下載並快取）。
  • 要永久更換預設模型，編輯 sam3_tools\config.py 的 DEFAULT_MODEL_ID。
  • 模型快取位於 %USERPROFILE%\.cache\huggingface\hub，舊模型不用時可整個資料夾刪除釋放空間。

8.4 ArcGIS Pro 大版本升級後（例如 3.6 → 3.7 / 4.0）

Pro 升級會附帶新的 arcgispro-py3 基底環境，舊的 clone 環境可能與新版不相容。標準處理流程：

  1. 升級 ArcGIS Pro。
  2. 刪除舊環境：開啟 Python Command Prompt 執行 conda env remove -n sam3_env（或直接刪除 %LOCALAPPDATA%\ESRI\conda\envs\sam3_env）。
  3. 重新執行 scripts\setup_env.bat 重建環境（模型權重快取仍在，不需重新下載）。
  4. 重啟 Pro、確認 Active Environment 為 sam3_env，工具箱不需重新加入。

8.5 版本紀錄建議

每次更新請在 README.md 的 Changelog 區塊記錄日期、變更內容與對應的 transformers/torch 版本（pip list 可查），方便回溯。
